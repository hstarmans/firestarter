# Maxwell Kinematic Dock Receiver Plate

![Maxwell Kinematic Dock Receiver Plate](preview.png)

Precision kinematic dock receiver PCB interface. Provides high-repeatability magnetic and kinematic mounting for quickly swapping or aligning the laser toolhead.

## Key Details
* **Mounting Principle:** Exact-constraint Maxwell kinematic clamp
* **Features:** Alignment ball sockets, magnetic clamp cutouts, and central laser pass-through
* **Repeatability:** Sub-pixel optical alignment repeatability after head replacement
