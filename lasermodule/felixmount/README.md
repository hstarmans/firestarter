# Carriage Mount Adapter (Felixmount)

![Carriage Mount Adapter (Felixmount)](preview.png)

Mechanical mounting adapter plate used to secure the laser scanhead assembly to CNC or 3D printer motion carriages.

## Key Details
* **Role:** Machine motion carriage mounting adapter
* **Mounting:** Standardized fastener pattern for CNC 3018 and carriage plates

*Part of the [Hexastorm (Firestarter)](../../README.md) open-hardware laser direct imaging project.*
