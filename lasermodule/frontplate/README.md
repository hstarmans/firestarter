# Scanhead Front Plate

![Scanhead Front Plate](preview.png)

Front wall of the scanhead enclosure. Features the precision optical scan slit through which the reflected laser beam exits towards the exposure bed.

## Key Details
* **Role:** Front enclosure wall and beam exit window
* **Features:** Laser scan slit aperture and structural interlocking tabs
