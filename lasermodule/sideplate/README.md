# Scanhead Side Plate

![Scanhead Side Plate](preview.png)

Structural side wall of the scanhead housing. Features castellated/interlocking tabs for rigid 3D box construction using PCB material.

## Key Details
* **Role:** Structural side wall of scanhead
* **Construction:** Interlocking tabbed FR4 construction
