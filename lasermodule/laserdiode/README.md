# Laser Diode Mount & Driver PCB

![Laser Diode Mount & Driver PCB](preview.png)

Carrier PCB for the laser diode module inside the scanhead housing. Provides pogo-pin connection to the back plate of the laserhead. Solder contacts provide opton to determine pin routing.

## Key Details

* **Function:** Laser diode mounting and modulation interface
* **Contacts:** Spring-loaded pogo pin pads and direct solder pads for high-speed modulation driver connection
* **Form Factor:** Compact circular/rectangular footprint fitting diode heatsink assembly
