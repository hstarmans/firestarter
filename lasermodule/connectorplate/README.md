# Scanhead Connector Plate

![Scanhead Connector Plate](preview.png)

Rear interface plate of the laser scanhead housing. Holds the high-density ribbon connector and routes power, laser diode modulation, and index sync signals to the main controller.

## Key Details
* **Role:** Electrical interconnect interface for scanhead
* **Connectors:** High-density locking connector cutout and strain relief

*Part of the [Hexastorm (Firestarter)](../../README.md) open-hardware laser direct imaging project.*
